# Русификатор PengPong

Проект добавляет отдельный язык `Русский`, устанавливает кириллические шрифты и
исправляет размеры отдельных элементов непосредственно в Unity UI-бандле.

Автор: **graf**. Бесплатный неофициальный проект без коммерческих целей.
Коммерческое распространение запрещено условиями проекта.
