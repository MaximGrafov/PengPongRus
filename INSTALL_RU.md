# Установка русификатора

Неофициальный русификатор **by graf** (https://steamcommunity.com/id/graf541/). Проект создан без коммерческих целей;
коммерческое использование и распространение запрещены. Устанавливая пакет,
пользователь принимает условия из `LEGAL_RU.md`.

## Требования

- лицензионная Steam-версия PengPong;
- Windows x64;
- Steam build ID `24838903`;
- закрытая игра во время установки.

## Установка

1. Закройте PengPong.
2. Запустите `PengPong_Russian_Setup.exe`.
3. Проверьте путь к папке, содержащей `PengPong.exe`.
4. Нажмите «Установить».
5. Запустите игру через Steam.
6. При необходимости выберите в настройках язык `Русский`.

Установщик добавляет BepInEx, плагин, перевод, два шрифта и согласованную пару
`UI-бандл + catalog.bin`. Оригиналы UI-файлов сохраняются в:

`BepInEx\plugins\PengPongRussian\backup`

## Удаление

1. Закройте PengPong.
2. Запустите тот же `PengPong_Russian_Setup.exe`.
3. Проверьте путь к игре.
4. Нажмите «Удалить / откатить» и подтвердите действие.

Установщик сначала восстановит оригинальные UI-бандл и `catalog.bin`, проверит
их хеши, затем удалит перевод, оба шрифта, плагин, его настройки и резервные
копии. Если других модов нет, также будут удалены BepInEx и его корневые
загрузочные файлы. При обнаружении других модов их файлы и BepInEx останутся.

Если оригинальные резервные копии отсутствуют, автоматическое удаление
остановится. В этом случае восстановите файлы игры через Steam: «Свойства» →
«Установленные файлы» → «Проверить целостность файлов игры».

Проверка файлов Steam остаётся запасным способом полного возврата файлов игры.

## Чёрный экран

Нельзя заменять только `.bundle`: Unity проверяет его CRC из `catalog.bin`.
Используйте полный установщик или `UPDATE_RUSIFIER.bat`, которые обновляют оба
файла согласованно.
